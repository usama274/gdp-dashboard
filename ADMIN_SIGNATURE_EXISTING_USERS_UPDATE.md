# Admin Signature Update for Existing Users

## What was updated

Admin can now add, replace, activate, or deactivate digital signatures and stamps for any user already created in the system.

This means signatures can be added later even when:

- user credentials have already been created;
- role has already been assigned;
- CEO, Trainer, Tutor/Mentor, QMR, Management, Principal Surveyor, or Technical Manager already exists in the users table;
- a previous signature already exists and needs replacement.

## How it works

1. Login as Admin.
2. Open Admin Control Center.
3. Go to Authorized Digital Signatures for Certificates.
4. Select either:
   - an existing user, or
   - Role Default Signature.
5. Upload signature image.
6. Upload stamp/seal if required.
7. Select certificate usage and authorization level applicability.
8. Save/replace signature.

## Certificate impact

The latest active signature is automatically used on:

- Training Completion Certificate;
- Refresher Training Completion Certificate;
- Training Authorization Certificate;
- level-wise authorization certificates.

## Control features

- Admin can deactivate previous signatures automatically.
- Admin can activate or deactivate any stored signature later.
- All actions are audit logged.
- Trainees cannot edit or replace signatures.
