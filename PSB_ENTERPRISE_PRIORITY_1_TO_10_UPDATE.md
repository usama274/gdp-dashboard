# PSB Enterprise Priority 1–10 Update

This package upgrades the PSB platform with additive modules while preserving existing functionality.

## Added / strengthened
1. Competency Matrix Engine with readiness and gap calculation.
2. New Building Survey operations with ITP, hold/witness points and stage gate acceptance.
3. Domain-based Plan Appraisal across six authorization domains.
4. Technical knowledge repository support through existing Interpretation Portal plus enterprise gap register.
5. Mobile Surveyor Evidence capture table and page.
6. Designer Portal with revision/comment flow.
7. Shipyard Portal with inspection request workflow.
8. AI/rule-based competency recommendations table and engine function.
9. Audit Readiness Engine for ISO 9001, ISO/IEC 17020, IMO RO Code and IACS PR7.
10. Workforce Forecasting engine.

## New roles
Designer and Shipyard Representative are added as external limited-access roles.

## Security / deployment
Existing Streamlit, Supabase/PostgreSQL and Render deployment files are retained. Schema changes are additive.
