# V20 Authorization Lifecycle & Reauthorization Update

This update adds the career-long authorization control layer for already-authorized personnel, not only trainees.

## Added roles
- Authorization Lifecycle Manager
- Authorization Board Member
- CPD Coordinator

## Added modules
- Authorization Lifecycle
- CPD & Refresher Control
- Monitoring Schedule
- Competency Board Review
- Rule Update Training Impact
- Reauthorization Status Center
- Authorization Lifecycle Gap Closure

## Professional lifecycle
Initial authorization → active authorization → monitoring → refresher/CPD → rule update training → technical interview / board review → renewal, restriction, suspension or expiry.

## Applies to
- In-Service Surveyor
- New Building Surveyor
- Plan Appraiser
- ISM/ISPS/MLC Auditor
- Technical Authority
- Technical Monitor

## State model
Authorized, Provisionally Authorized, Restricted, Suspended, Expired, Reauthorization Due.

## Key rule
Training pass alone is not enough. To keep authorization valid, the person must complete refresher training, CPD, monitoring, rule update awareness and reauthorization review.
