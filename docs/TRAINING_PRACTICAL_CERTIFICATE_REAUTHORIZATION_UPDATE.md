# PSB V3 Training → Practical → Authorization Update

This update adds the world-class/IACS-style progression model requested by PSB.

## Added
- Training-to-Practical Eligibility Engine
- Trainer-defined progression gates by pathway and scope
- In-Service, New Building and Plan Appraisal pathway unlock rules
- Digital Training Attestation certificate based on PSB-PTQ20-F03
- Digital Authorization/Reauthorization certificate based on PSB-PTQ20-F02
- Admin-managed signer/signature settings
- QR verification URL field
- 3-year default authorization validity
- Reauthorization/revalidation engine
- CPD, refresher training, activity, NCR/complaint and QMR clearance review
- Role/activity world-class gap analysis register
- MCQ question difficulty and category columns for mastery analysis

## Correct Competency Logic
Training pass alone does not authorize a person. The correct gate is:

Training + MCQ + case/practical + witness/supervised or joint/independent plan review + tutor assessment + technical interview + QMR/CRB/management approval = authorization certificate.
