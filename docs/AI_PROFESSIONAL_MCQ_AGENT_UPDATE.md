# AI Professional MCQ Agent Update

This update changes MCQ generation from simple word-blank extraction to a professional, training-specific AI-agent style generator.

## What happens when trainer clicks Generate Professional AI MCQs

1. The app reads the uploaded training material.
2. It infers the training domain: In-Service Survey, New Building Survey, Plan Appraisal, QMS/Audit, Hull, Machinery, Electrical, Statutory, Materials, etc.
3. It extracts important topics and learning objectives.
4. It creates scenario/case-based questions rather than memory-only questions.
5. It creates realistic distractors and one best answer.
6. It tags every question by category and difficulty.
7. It creates an explanation, reference source and quality score for every MCQ.
8. It stores weakness-analysis data after the trainee attempts the test.

## Quality rules

- At least 50–100% scenario/case-based questions, trainer controlled.
- Difficulty mix: Basic, Intermediate, Advanced, Expert.
- Every MCQ must have one best answer.
- Every MCQ must be linked to the actual training content.
- Distractors must look realistic but remain clearly wrong.
- Every MCQ includes explanation and learning objective.

## Professional purpose

The test should evaluate judgment, rule application, evidence control, technical escalation and classification-society professionalism, not only memorization.
