# Role Activity Gap Analysis

| Role | Main Activities | Remaining Improvement | Target |
|---|---|---|---|
| Admin | Users, roles, permissions, backup, audit trail | Quarterly access review and delegation matrix | Controlled governance |
| CEO | Critical strategic KPIs | Red/Amber/Green strategic board | Executive governance |
| Management | KPI, authorization, workforce planning | 3/6/12 month manpower forecast | Resource readiness |
| Trainer | Courses, MCQ, attendance | Course versions and training effectiveness | Learning quality |
| Tutor/Mentor | Witness and supervised evidence | Structured 1-5 rubric | Better competency evidence |
| Technical Authority | Technical reviews and interpretations | Mandatory technical decision repository | Consistent rulings |
| QMR | QMS, CAPA, audit readiness | Clause-wise evidence tracker | Audit readiness |
| Surveyor | In-service survey execution | Mobile evidence and scope lock | Strong field control |
| New Building Surveyor | Construction stages and inspections | Full ITP and trial workflow | Project stage control |
| Plan Appraiser | Drawing review and approval | Comment closure and revision routing | Drawing lifecycle control |
| Coordinator | Assignment | Risk/authorization/availability block | Safe allocation |
| Trainee | Training and competency path | Personal career gap dashboard | Faster readiness |
| Designer | Drawing submission | Revision tracker and comment closure | External collaboration |
| Shipyard Representative | Inspection requests | NCR/stage closure tracker | External project control |
