# Appraised / Approved Drawing Distribution Upgrade

This update merges the appraised drawing distribution workflow into the PSB Enterprise app.

Added controls:
- Plan appraiser sends marked-up/appraised drawing to designer.
- Drawing comment register.
- Designer response and revised drawing upload.
- Revision chain and current/superseded status.
- Approved/stamped drawing distribution to shipyard, surveyors, document controller and management.
- Surveyor dashboard for latest approved drawings.
- Surveyor acknowledgement before inspection.
- Latest revision verification before inspection; outdated drawings are blocked.
- Superseded drawing register.
- Digital thread linking designer submission, plan appraisal, approved drawing, ITP, inspection request, NCR, survey report and certificate.

Professional classification-society value:
- Prevents survey/inspection against old drawing revisions.
- Provides traceability from design comments to field execution.
- Ensures appraised drawing is routed to the assigned surveyor and shipyard.
- Creates auditable evidence for QMS, ISO/IEC 17020 and RO-style technical control.
