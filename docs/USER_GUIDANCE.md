# User Guidance

## Getting Started
- Sign in with your assigned credentials.
- Use the sidebar to navigate to Maritime Registry, Maritime Surveys, My Training, and Certificates.
- Switch between light and dark themes from the sidebar.

## Working with Surveys
- Select the relevant survey type.
- Complete each checklist item, update remarks, and submit the checklist when complete.
- Use the project information panel to view system metadata and version information.
