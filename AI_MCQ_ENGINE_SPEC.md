
# AI Professional MCQ Engine

Purpose:
Generate classification-society quality assessments from uploaded training material.

Rules:
- Analyze PDF/PPT/DOCX content.
- Build topic map.
- Generate 4 difficulty levels: Basic, Intermediate, Advanced, Expert.
- Minimum 70% scenario/case-based questions.
- Maximum 30% factual recall questions.
- Each question tagged with:
  - Domain
  - Topic
  - Difficulty
  - Learning objective
  - Reference source

Question Categories:
- SOLAS
- MARPOL
- MLC
- RO Code
- Hull
- Machinery
- Electrical
- Statutory
- Alternative Fuels
- Plan Appraisal
- Survey Practice

Quality Checks:
- No ambiguous answers.
- One best answer only.
- Explanation required for every answer.
- Distractors must be realistic.
- Randomize options.

Weakness Analysis:
- Topic mastery score.
- Training recommendation.
- Retest recommendation.
- Competency-gap linkage.

Eligibility:
Trainer configures:
- Pass mark
- Mandatory topics
- Required difficulty mix
- Practical eligibility threshold

Output:
Professional certification-grade assessment.
